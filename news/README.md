# Новости приложения

Единственный источник ленты — корневой файл `news.json`.

Чтобы добавить новость:

1. Загрузить изображение в новую папку `news/YYYY-MM-DD-slug/`.
2. Добавить новую запись в начало массива `news.json`.
3. Не удалять и не изменять прежние записи: они просто смещаются ниже.
4. Открыть Pull Request и дождаться проверки `Validate application / validate`.

Отдельные `post.json`, генераторы и автоматические коммиты для новостей больше не используются. Проверка только подтверждает корректность `news.json`, порядок дат и наличие изображений; она не изменяет ветку.
